# RoboFlow

RoboFlow is a planned JavaFX-based desktop application that will simulate the operations of an automated warehouse with multiple autonomous robots. The system will model warehouse shelves, products, customer orders, obstacles, charging stations, packing areas, and dispatch zones.

The project will focus on how robots can receive and prioritize warehouse tasks, select suitable robots, calculate efficient routes using pathfinding algorithms, avoid obstacles and collisions, collect products, and deliver completed orders to the packing area. The simulator will provide a visual interface where users can monitor robot movement, order status, battery levels, routes, and warehouse activity in real time.

Planned technologies and concepts include Java, JavaFX, MySQL, JDBC, object-oriented programming, data structures and algorithms, A* pathfinding, task scheduling, multithreading, synchronization, collision avoidance, and simulation analytics.
